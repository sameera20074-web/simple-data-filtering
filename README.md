# Simple Data Filtering

Create a collection of student records and filter students based on marks, age, or department.

## Objective
Understand how conditions can be used to filter structured data.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Filtering Operations
1.  Marks >= 75 - To find top performers
2.  Department == CSE and Age <= 21 - To find young CSE students

## How to Run
pip install -r requirements.txt
python main.py

## Output
Filtered student lists based on conditions.
